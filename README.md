# GrocerWise

GrocerWise is a premium grocery price comparison application built with React, Redux, and Tailwind CSS. It helps users find the best deals on everyday items across major supermarkets like Woolworths, Coles, and Aldi.

## Features

- **Smart Search**: Real-time search for grocery items.
- **Store Filtering**: Filter results by store (Woolworths, Coles, Aldi).
- **Price Comparison**: clear display of prices and unit prices.
- **Premium UI**: Modern, responsive design with glassmorphism effects.

## Tech Stack

- **React 19**: Frontend library.
- **Redux Toolkit**: State management.
- **Tailwind CSS v4**: Utility-first CSS framework.
- **Vite**: Build tool and dev server.

## Getting Started

1.  **Install dependencies**:
    ```bash
    npm install
    ```

2.  **Run the development server**:
    ```bash
    npm run dev
    ```

3.  Open [http://localhost:5173](http://localhost:5173) in your browser.
